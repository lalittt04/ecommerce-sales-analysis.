# E-Commerce Sales Analysis Using SQL

## Project Overview

This project analyzes sample e-commerce sales data using MySQL to identify revenue trends, product performance, customer spending, and city-wise sales.

## Technologies Used

* MySQL
* SQL
* GitHub

## Dataset

The dataset contains sample sales records with the following columns:

* Order ID
* Customer Name
* Product Name
* Category
* Quantity
* Price
* Order Date
* City

## SQL Concepts Used

* SELECT statements
* Aggregate functions (SUM)
* GROUP BY and ORDER BY
* Date functions
* LIMIT
* Revenue calculations

## Business Questions Answered

1. What is the total sales revenue?
2. Which product categories generate the most revenue?
3. Which products sell the highest quantities?
4. Which cities generate the most revenue?
5. How does revenue change monthly?
6. Which order has the highest value?
7. How much does each customer spend?

## Project Goal

To demonstrate SQL querying and data analysis skills by answering business questions using sample e-commerce sales data.
